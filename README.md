# Unitask

Unitask is a cutting-edge freelancing platform tailored for students, enabling them to earn while they learn. By connecting students with freelancing opportunities, Unitask fosters a community of young professionals ready to showcase their skills. Built with a modern tech stack, the platform ensures a seamless, secure, and efficient user experience.

## Features

### User Authentication
- **Secure Login & Registration**: Robust authentication system with password encryption.
- **OAuth Integration**: Login via Google, Facebook, and other third-party providers.
- **Password Recovery**: Easy-to-use password reset functionality.

### User Profiles
- **Customizable Profiles**: Add personal and professional details.
- **Portfolio Showcase**: Upload and display portfolio items.
- **Profile Viewing**: Explore other users' profiles.

### Task Management
- **Task Creation**: Post tasks with detailed descriptions, categories, and deadlines.
- **Task Updates**: Edit or delete tasks as needed.
- **Reminders**: Automated notifications for task deadlines.

### Marketplace
- **Gig Browsing**: Explore tasks posted by other users.
- **Advanced Filters**: Search by category, budget, and deadline.
- **Detailed Listings**: View comprehensive gig descriptions and requirements.

### Real-Time Chat System
- **Instant Messaging**: Communicate with other users in real-time.
- **Group Chats**: Collaborate on tasks with multiple users.
- **Mobile-Friendly Interface**: Optimized for seamless communication on the go.
- **Notifications**: Alerts for new messages.

### Notifications
- **Push Notifications**: Stay updated on task changes, messages, and reminders.
- **In-App Alerts**: Notification bell and banners for quick access.

### Order Management
- **Order Placement**: Seamlessly place and manage orders.
- **Milestone Tracking**: Monitor progress through defined milestones.
- **Order Confirmation**: Review and approve completed tasks.

### Payment Integration
- **Secure Transactions**: Integrated payment gateway for safe payments.
- **Escrow System**: Funds are held securely until task completion.
- **Invoices**: Generate and view payment history.

### Admin Dashboard
- **User Management**: Add, edit, or remove users.
- **Task Oversight**: Monitor and manage tasks and categories.
- **Analytics**: Generate reports to track platform performance.

### Mobile Responsiveness
- **Optimized Design**: Fully responsive for mobile and tablet devices.
- **Dedicated Views**: Tailored mobile interfaces for chat and task management.

### Additional Features
- **Dark Mode**: Enhanced user experience with a dark theme.
- **Error Handling**: Comprehensive feedback for errors and issues.
- **Email Notifications**: Stay informed with email updates.

## Tech Stack

### Frontend
- **React.js**: Dynamic and responsive user interface.
- **Tailwind CSS**: Modern and efficient styling.
- **Vite**: Fast development and build processes.

### Backend
- **Node.js & Express.js**: Scalable server-side logic.
- **MongoDB**: Flexible and efficient database management.
- **Azure Storage**: Secure file uploads and storage.

### Real-Time Communication
- **Socket.io**: Enables real-time chat and notifications.

### Deployment
- **Vercel**: Fast and reliable deployment platform.

### Other Tools
- **ESLint**: Code linting for consistent quality.
- **PostCSS**: Advanced CSS processing.

## Installation

1. **Clone the Repository**:
    ```sh
    git clone <repository-link>
    ```

2. **Navigate to the Project Directory**:
    ```sh
    cd unitask
    ```

3. **Install Dependencies**:
    ```sh
    npm install
    ```

---

## Usage

1. **Start the Development Server**:
    ```sh
    npm run dev
    ```

2. **Access the Application**:
    Open your browser and navigate to `http://localhost:3000`.
